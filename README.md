# Ревью pull request: модуль заказов

## Контекст

Вы присоединились к команде небольшого интернет-магазина электроники. Коллега открыл pull request, в котором добавил:

- модуль товаров (`src/products`) с каталогом и остатками на складе;
- модуль заказов (`src/orders`): создание заказа, применение промокода, просмотр, отмена и удаление заказа администратором;
- гард для административных эндпоинтов (`src/common/admin.guard.ts`);
- юнит-тесты для сервиса заказов.

Хранилище пока в памяти: базу данных команда подключит отдельным PR, поэтому само по себе отсутствие БД обсуждать не нужно. А вот то, как код поведёт себя, когда БД появится, обсуждать можно.

Интеграция с платёжным провайдером тоже пока заглушка (`chargePayment`).

## Эндпоинты

| Метод  | Путь                 | Описание                             |
| ------ | -------------------- | ------------------------------------ |
| GET    | `/products`          | каталог товаров с остатками          |
| POST   | `/orders`            | создать заказ                        |
| GET    | `/orders?userId=1`   | список заказов пользователя          |
| GET    | `/orders/:id`        | заказ по id                          |
| POST   | `/orders/:id/cancel` | отменить заказ                       |
| DELETE | `/orders/:id`        | удалить заказ (только администратор) |

Пример тела запроса для создания заказа:

```json
{
  "userId": 1,
  "customerEmail": "ivan@example.com",
  "address": "Москва, ул. Тверская, 1",
  "items": [
    { "productId": 1, "quantity": 1, "price": 89.99 },
    { "productId": 2, "quantity": 2, "price": 24.9 }
  ],
  "promoCode": "WELCOME10"
}
```

Удачи!
